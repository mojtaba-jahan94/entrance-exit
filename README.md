# ⏱️ سامانه هوشمند مدیریت تردد و کارکرد (Entrance-Exit)

یک وب‌اپلیکیشن مدرن، سریع و اختصاصی برای **ثبت ورود و خروج، شیفت شناور، محاسبه خودکار اضافه کاری، تاخیر، تعجیل و کاردکس مرخصی‌ها** مبتنی بر **تقویم هجری شمسی (جلالی)** و قوانین کار اختصاصی شما.

---

## ✨ شخصی‌سازی و قوانین کاری اختصاصی

### ۱. 🕒 شیفت کاری شناور (شنبه تا چهارشنبه)
* **بازه ورود شناور مجاز:** از **۰۸:۳۰** الی **۰۹:۳۰** صبح (ورود در این بازه تاخیر محسوب نمی‌شود).
* **بازه خروج متناظر:** از **۱۷:۰۰** الی **۱۸:۰۰** عصر.
* **مدت حضور الزامی روزانه:** **۸ ساعت و ۳۰ دقیقه** (۵۱۰ دقیقه).
* **کسر خودکار تایم ناهار/استراحت:** **۳۰ دقیقه** (که طبق قانون کارگاه از ساعات کلی کار کسر می‌شود و **کارکرد خالص روزانه ۸ ساعت** لحاظ می‌گردد).
* **ساعت خروج هدف و شمارش معکوس:** نمایش زنده ساعت دقیق پایان شیفت به محض ورود (مثلاً ورود در ۰۸:۴۰ ⬅️ خروج موظفی در ۱۷:۱۰) به همراه پروگرس‌بار زنده و تایمر اضافه کاری.

### ۲. 🗓️ پنج‌شنبه‌ها (نیمه‌وقت ۴.۵ ساعته)
* **مدت حضور الزامی پنج‌شنبه:** **۴ ساعت و نیم** (۲۷۰ دقیقه).
* در روزهای پنج‌شنبه تایم ناهار کسر نمی‌شود و حضور مازاد بر ۴.۵ ساعت اضافه کاری و کمتر از آن کسر کار است.

### ۳. 🌴 سهمیه و کاردکس مرخصی‌ها
* **سهمیه ماهانه:** **۲.۵ روز در ماه** (معادل **۲۰ ساعت** کارکرد مفید).
* نمایش همزمان مانده به دو واحد **روز** و **ساعت**.
* امکان ثبت مرخصی **ساعتی (پاس ساعتی)**، **نیم‌روز (۴ ساعت)** و **روزانه کامل (۱ روز = ۸ ساعت)** با کسر هوشمند از سهمیه ماهانه.

### ۴. 🚀 امکانات و آپشن‌های ارتقایافته و بهینه
* **داشبورد آماری بنتو (Bento Grid):** نمایش کارکرد خالص، تراز کل ماه (تفاضل اضافه کار و کسر کار)، تاخیرات بعد از ۰۹:۳۰، تعجیل، و مانده مرخصی با نمودار پیشرفت.
* **تخمین مالی اختیاری:** امکان درج دستمزد ساعتی در تنظیمات برای برآورد ریالی ارزش اضافه کاری ماه.
* **جدول تردد پیشرفته ماهانه:** با ستون‌های جدید «خروج موظفی هدف» و «تراز روز (+ / -)»، فیلتر پنج‌شنبه‌ها، فیلتر تاخیر/تعجیل، و ردیف جمع کل فیش ماهانه در انتهای جدول.
* **ثبت تردد دستی سریع و پیش‌نمایش آنی کارکرد خالص.**
* **خروجی اکسل رسمی (`.xlsx`) و پرینت استاندارد فیش ماهانه.**
* **پشتیبان‌گیری کامل (JSON) و قابلیت بازنشانی سریع داده‌ها.**

## 🚀 راهنمای راه‌اندازی و اجرا

### پیش‌نیازها
* Node.js نسخه 18 یا بالاتر
* npm یا pnpm

### نصب پکیج‌ها
```bash
npm install
```

### اجرای محیط توسعه (Dev Server)
```bash
npm run dev
```
سپس آدرس `http://localhost:5173` را در مرورگر باز کنید.

### ساخت نسخه نهایی (Production Build)
```bash
npm run build
```
فایل‌های کامپایل‌شده در پوشه `dist` تولید خواهند شد.

## 🛠️ پشته فنی (Tech Stack)
* **Frontend:** React 19 + TypeScript + Vite
* **Styling:** Tailwind CSS + Custom Glassmorphism UI
* **Icons:** Lucide React
* **Calendar:** `jalaali-js`
* **Excel:** SheetJS (`xlsx`)
* **Animations & FX:** Canvas Confetti
