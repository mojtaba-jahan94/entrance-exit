# ⏱️ سامانه هوشمند مدیریت تردد و کارکرد (Entrance-Exit)

یک وب‌اپلیکیشن مدرن، سریع و کاربرپسند برای **ثبت ورود و خروج، محاسبه خودکار اضافه کاری، تاخیر، تعجیل و مدیریت مرخصی‌ها** مبتنی بر **تقویم هجری شمسی (جلالی)** و قوانین کار.

---

## ✨ قابلیت‌ها و ویژگی‌های کلیدی

### ۱. 🕒 ثبت تردد روزانه با یک کلیک (Clock In / Clock Out)
* دکمه بزرگ تعاملی ثبت ورود و خروج با ثبت خودکار ساعت و دقیقه فعلی.
* **تایمر و کرونومتر زنده:** نمایش زمان کارکرد زنده از لحظه ورود با شمارنده دقیق.
* انیمیشن جشن پایانی (Confetti) هنگام ثبت خروج.
* امکان درج مدت استراحت / صرف ناهار روزانه.

### ۲. 📅 انطباق ۱۰۰٪ با تقویم هجری شمسی (جلالی)
* شروع هفته از **شنبه** و خاتمه در **جمعه**.
* مدیریت دوره‌های ماهانه از **فروردین تا اسفند** با پشتیبانی دقیق از سال‌های کبیسه شمسی.
* شناسایی خودکار **تعطیلات رسمی تقویم ایران** و عدم محاسبه غیبت در روزهای تعطیل.
* انتخاب‌گر تقویم شمسی در کلیه بخش‌های فرم دستی و مرخصی‌ها.

### ۳. ⚙️ موتور هوشمند محاسبات کارکرد
* **محاسبه دقیق تاخیر (Delay):** محاسبه تاخیر با در نظر گرفتن فرجه مجاز شناوری (Grace Period).
* **محاسبه خروج زودهنگام (Early Leave / تعجیل):** تفکیک خروج پیش از پایان موظفی.
* **محاسبه اضافه کاری عادی و تعطیلات:** محاسبه دقیق ساعات حضور مازاد بر موظفی روزانه و اضافه کاری روزهای تعطیل با ضرایب مجزا.
* **پیکربندی روزهای پنج‌شنبه:** قابلیت تعیین به عنوان «نیمه‌وقت»، «تعطیل کامل» یا «روز کاری کامل».

### ۴. 📋 مدیریت و کاردکس مرخصی‌ها (Leave Management)
* ثبت مرخصی **ساعتی** (پاس ساعتی با تعیین بازه زمانی) و **روزانه** (استحقاقی، استعلاجی، بدون حقوق).
* محاسبه خودکار مانده مرخصی با سهمیه ماهانه (پیش‌فرض ۲.۵ روز معادل ۲۰ ساعت در ماه).
* بهینه‌سازی و به‌روزرسانی کارکرد همان روز به عنوان روز مرخصی.

### ۵. 📊 داشبورد آماری بنتو (Bento Dashboard)
* کارت‌های شاخص کلیدی:
  * کارکرد مفید ماه با نوار پیشرفت درصد تحقق موظفی.
  * مجموع اضافه کاری ماه (تفکیک عادی و روزهای تعطیل).
  * مجموع دقایق تاخیر و کسر کار.
  * مانده مرخصی استحقاقی و تعداد روزهای حضور.

### ۶. 📑 جدول ماهانه، خروجی اکسل و نسخه پشتیبان
* مشاهده و فیلتر ریز ترددها بر اساس سال و ماه شمسی.
* فیلتر سریع: فقط تاخیرها، اضافه کاری‌ها، مرخصی‌ها، روزهای تعطیل.
* **خروجی اکسل رسمی (`.xlsx`):** دانلود فیش و جدول کامل کارکرد با سرستون‌های فارسی و استاندارد حسابداری.
* **قابلیت چاپ و خروجی PDF:** آماده برای پرینت یا ذخیره به عنوان فیش کارکرد ماهانه.
* **پشتیبان‌گیری کامل (JSON):** دانلود کلیه اطلاعات و بازیابی آسان در صورت تغییر مرورگر یا دستگاه.

## 🚀 راهنمای راه‌اندازی و اجرا

### پیش‌نیازها
* Node.js نسخه 18 یا بالاتر
* npm یا pnpm

### نصب پکیج‌ها
```bash
npm install
```

### اجرای محیط توسعه (Dev Server)
```bash
npm run dev
```
سپس آدرس `http://localhost:5173` را در مرورگر باز کنید.

### ساخت نسخه نهایی (Production Build)
```bash
npm run build
```
فایل‌های کامپایل‌شده در پوشه `dist` تولید خواهند شد.

## 🛠️ پشته فنی (Tech Stack)
* **Frontend:** React 19 + TypeScript + Vite
* **Styling:** Tailwind CSS + Custom Glassmorphism UI
* **Icons:** Lucide React
* **Calendar:** `jalaali-js`
* **Excel:** SheetJS (`xlsx`)
* **Animations & FX:** Canvas Confetti
